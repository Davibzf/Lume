# Segurança

Relate vulnerabilidades pela aba **Security → Report a vulnerability** do repositório. Se esse recurso estiver indisponível, abra uma issue sem publicar arquivos pessoais nem detalhes exploráveis.

Os downloads oficiais são os anexos das [Releases](https://github.com/Davibzf/Lume/releases). Confira os hashes em `SHA256SUMS.txt`. Um hash verifica integridade; os executáveis ainda não possuem assinatura comercial.

O Lume processa a mídia localmente. A rede é usada para baixar o modelo público necessário e o download é validado por SHA256. Não há telemetria nem upload de gravações. Modelos, logs e transcrições nunca devem entrar no repositório.
