Lume é um transcritor local para Windows 10/11 x64. Inclui arrastar e soltar, qualidade Turbo/Máxima, revisão e exportação TXT/SRT/VTT.

**Para instalar:** baixe **Lume-Setup.exe**, execute e escolha Instalar. Não precisa de Python ou GPU. O modelo é baixado e verificado automaticamente no primeiro uso; depois, a transcrição funciona offline.

Alternativas: MSI para instalação direta ou ZIP portátil. Todos os arquivos da pasta portátil devem permanecer juntos.

Código do Lume sob MIT. Esta release inclui o código-fonte correspondente e a configuração do FFmpeg LGPL usado no pacote. Confira os avisos de terceiros e `SHA256SUMS.txt`.

Compatibilidade anunciada: Windows 10/11 de 64 bits, Intel/AMD. Windows de 32 bits, macOS e Linux não possuem executável oficial; ARM64 não foi validado. Os binários ainda não têm assinatura comercial. A transcrição pode conter erros e deve ser revisada.
